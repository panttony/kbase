# Migrations

SQL-миграции для PostgreSQL лежат в этой директории и встраиваются в бинарь
через `//go:embed` (см. `internal/storage/migrate.go`).

## Механизм

- При старте приложения (`storage.New`) выполняется `migrate()`: файлы
  `*.sql` читаются из embedded-FS, сортируются лексикографически и применяются
  по одному, каждая — в собственной транзакции.
- Применённые миграции фиксируются в таблице `schema_migrations`
  (имя файла + время применения). Повторный запуск миграции — no-op.

## Соглашения

- Имя файла: `NNN_description.sql`, где `NNN` — порядковый номер, начиная с `001`.
- Миграции выполняются в лексикографическом порядке.
- Только идемпотентные и обратимые DDL; без данных внутри миграций.

## Текущие миграции

- `001_init.sql` — таблицы `documents`, `versions`, `tags`, `document_tags`
  + индексы (схема из `docs/system-design.md`, раздел 5).
- `002_...` — последующие изменения схемы (по мере необходимости).
